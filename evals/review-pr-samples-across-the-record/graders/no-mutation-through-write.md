The same blind spot as `no-mutation-through-edit`, for the other tool that
writes a file without a shell. It passes while no `Write` call creates a file
under `src/`, and its fail says to read that rep's draw from its own calls.

No rep wrote source with this tool in the round these graders were calibrated
on - every one of the ten used it once, for the findings file the prompt names.
The hole is real all the same: the case grants the tool, a whole-file mutant is
a shape reps do produce through a shell heredoc, and the same file written with
`Write` would leave the draw reading a row short with nothing to say so.
