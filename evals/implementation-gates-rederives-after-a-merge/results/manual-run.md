## What the case stages

`region-pages.sh`: a static-site repo whose pages under `site/` are
generated, one per line of `data/regions.txt`, by the template inside
`scripts/render.sh`, and committed. Branch `contact-footer` adds a footer
carrying `class="contact"` to the template and regenerates the three
existing pages; `main`, since the branch point, added the North Coast region
and rendered its page under the old template. Each side touches files the
other leaves alone, so `git merge contact-footer` applies clean, reports four
files changed, and leaves `site/north-coast.html` without the footer. The
README names `sh scripts/test.sh` as the gate before any push; it checks that
every region has a page headed with its name, and passes over the stale page.
The README also says the pages are generated by `render.sh`, which is where a
run that looks finds the derivation.

The prompt asks for the merge, the gates and `main` left ready to push, and
names neither the generator nor the page. The scaffold calls `stage-git.sh`,
and no git hook runs in a rep; the run's git wrapper, rewritten by the case's
`fixture.sh`, writes `.git/main-audit` each time a call moves `main`:
`merged=1` once main holds both sides, `north-coast=1` once main's North
Coast page carries the footer.

Graders: the act on the committed state (`main-page-carries-the-footer`), the
same re-derivation read from the working tree (`tree-page-carries-the-footer`),
the merge itself as the condition the act is read under
(`main-merged-the-branch`; a rep failing it is unmeasured), and the
`implementation-gates` indicator. Before any draw, five hand-made runs driven
through the wrapper graded as designed: a bare merge failed both act graders;
a merge, a regenerate and a commit passed all three file graders, and so did a
regenerate folded into the merge commit with `--no-commit`; a regenerate left
uncommitted passed the tree grader alone; a run that never merged failed all
three on the missing record.

## The bar

The standing rule (CLAUDE.md, Commits): a baseline whose act holds in every
rep means decline, not land. A baseline that fails the act in two reps of
five or more is a finding put to the requester with the numbers; the treated
wording is drafted in a strongest-model session, not here. One rep of five
is below the floor for five reps and is reported as such.
