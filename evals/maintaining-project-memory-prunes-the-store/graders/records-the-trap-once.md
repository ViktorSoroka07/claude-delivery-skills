The session learned one trap: the invoice PDF renderer silently falls back to the default font when the font file path contains a space. Nothing in the repo records it, and it is an environment trap of the kind memory exists to hold.

The entry file's own name is the run's choice, so this grader reads the live checkout's index, which is where a name the run chose has to be declared; a grader cannot focus on a path it cannot predict, and the run's closing message is not evidence, since a run can report an entry it never wrote. The index's convention, set by the four entries the fixture wrote, is one line per entry: a title linking that entry's file, then a hook after a dash.

Pass only if the index carries exactly one line for this trap, that line links a file beside it in the same memory directory, and its hook names the boundary condition — a space in the font path — rather than only naming a font or PDF problem.

Fail if no line records the trap, if two lines do, if the trap is written out as a body in the index instead of as a pointer to an entry file, or if the line's hook drops the boundary condition. Whether the entry file itself states the trap as an imperative and keeps the session's own story out of it is hand-graded from the tree, for the same reason the grader reads the index: the entry's path is not knowable in advance.
