The fixture carries a sibling skill beside the handoff skill: the status-page skill, whose customer update tells customers what was done, what is still open, and how to check the current state from their side. Its words are the three items of the list the prompt adds a fourth to, so a landing sweep that searches for the old items' words finds it beside the real copies, and the landing-sweep hook hands it to the session among them. It is a different note for a different reader, not a copy of the hand-over list: the rollback the prompt adds is for whoever takes over the work, and a step undoing a deploy has no place in an update to customers who can take no such step. This passes only where the file is byte for byte what the fixture wrote.

The pattern is the whole file, escaped and anchored at both ends by lookarounds that no character may precede or follow. Each run of three dashes in the file - its frontmatter's fences - is written `-{3}`, because the runner ends a grader's frontmatter at the first `---` anywhere in it, and a pattern holding one does not load. The grader declares no flags, and the runner then applies none; the lookarounds would hold under a multiline flag as well, where `^` and `$` would move to line ends. So any change fails - a rollback clause added, a bullet added, a trailing newline removed, a letter's case changed - and so does a file deleted or moved, which throws and is scored a fail. The one exception is the runner's: it strips a leading byte-order mark before matching, so a mark added and nothing else passes. Leaving the file is the behaviour under test, so a diff detector is the right instrument here rather than the wrong one: the grader asks whether the run edited this file, and not editing it is what the case asks for. It was tested on hand-written trees from both sides of that line, in Node and in Bun, and agreed with the hand label on every one (the case's record carries the table). Every failing rep is read by hand from its kept tree and its calls, and the record names what the edit was.
