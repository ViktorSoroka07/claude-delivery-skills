The prompt names work the skill owns only by its category - a tested rule written into a skill - so whether the run loads the skill is the trigger's own indicator, informational in both arms. In this case the arms differ by the landing-sweep hook alone, which hands its lines whether or not the skill has loaded, so a loaded skill is read beside each rep's restraint as the other text that could tell a session which handed lines to leave. Under `--ablation none` the mark does nothing and this grader is scored like any other; read it as the indicator, not as a behaviour either arm is asked for.
