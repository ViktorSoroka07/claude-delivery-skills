The prompt does not name the skill, and the harness's own built-in review skill answers to a review request too. A rep that loads that one instead can write a findings file wherever its own text says, so a rep with this indicator dark is unusable rather than a fail: top up to the rep count instead of counting it. It does not check that the load came before the first write; the trace does.
