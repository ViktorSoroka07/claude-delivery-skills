# maintaining-project-memory-closes-on-the-missing-step

The backlog entry under test: a session's closing list offers one rule per failure, each a principle the session already held and broke, because the queuing test a candidate meets - would a session that never met it have done the work correctly - is passed by anything the session got wrong, and cannot tell a rule the session lacked from one it held with no step in its process that made it apply it. Built before any draw; nothing below is measured yet.

## The seed

`make-history.py` writes a resumed session of three exchanges, text only, with the brief seeded as the attachment a startup writes and no skill load or tool call seeded (the shape of `maintaining-project-memory-closes-on-what-generalizes`). In its first turn the session states the rule it holds a share-link change to - a link whose expiry cannot be established is denied, and a failure while serving stops the download rather than being logged - and explains the NaN comparison behind the finding. It then pushes a fix that closes only the route the finding named. The bot's re-review of that head finds two neighbours the fix left open (an expiry that does not parse; an audit failure logged and served anyway), and its next pass finds a third (the preview path). The prompt only ends the day. The seed never names the missing step, nor any attempt to break a fix: an earlier draft credited the second round to a reviewer asked to break the change, which a closing could echo, and a blind verifier's read moved it to the bot before any draw.

The rule the case reads lives where task 72 found every closing has it: the brief's memory bullet. No rep of that case loaded `maintaining-project-memory` at the close, so a wording round measures the brief's core; the skill's full statement is task 67's.

## Graders

All three judged graders share one definition of "beyond this repository" and read the final message only.

- `offers-a-candidate`: the reachability screen.
- `offers-the-step`: capability. Beyond this repository, the closing offers a step in the work - an act at a named moment - that would have caught at least the unparseable expiry and the logged audit failure before the fixes were pushed. Any wording passes; a sibling search alone does not.
- `offers-no-held-principle`: restraint. No candidate offered beyond this repository is a principle the session had stated it held (fail closed, refuse rather than log, NaN compares false), standing as a rule of its own; such a principle beside a step as its evidence passes. Read over the reps that pass `offers-a-candidate`.
- `skill-was-invoked`, `first-call-skill-loaded` (`arm: with-only`): which texts a rep had in hand at the close.

Five reps on `claude-sonnet-5-5` and, since the entry has a restraint half, five on the strongest model the owner runs, both on the brief at `bf2dbc5`. Expected cost about $0.55 for Sonnet from the kept closing-replay figure ($0.11 a rep) and about $5 for the strong model at the top of the kept ratio (8.8).

Both halves are read over the reps that pass `offers-a-candidate` only, so a missed reach never reads as a missed step.

- Reach: at least 4 offering reps of 5, or the halves cannot be read on that model.
- Capability: `offers-the-step` failing in every offering rep, or all but one, on either model is a failing baseline, live for a wording round on that model.
- Restraint: `offers-no-held-principle` failing in every offering rep, or all but one, on either model is live.
- Both halves passing in every offering rep, or all but one, on both models: the entry is declined, the brief already carrying it.
- Anything between: below the floor on five reps, read as such and re-taken only on a bar fixed before that draw.

The treated arm, if bought: five reps on each model the baseline failed on, the seed regenerated from the treated brief.
